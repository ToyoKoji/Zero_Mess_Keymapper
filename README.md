# Zero Mess Keymapper

ZMKファームウェアのキー配置を、ブラウザ上で視覚的に編集するためのエディタです。
インストール不要・単一HTMLファイルで動作し、**US配列で作った配置をJIS環境用に自動変換**できます。

名前は **ZMK** のバクロニム。「配列のこんがらがり（mess）をゼロにする」という狙いを表しています。

👉 **[エディタを開く](https://ToyoKoji.github.io/Zero_Mess_Keymapper/)**

---

## これは何のためのツール?

ZMKのキー配置は `.keymap` というテキストファイルで記述しますが、記号の配置を考えるのも、レイヤーを行き来しながら全体を把握するのも、テキストだけでは骨が折れます。このツールは、実際のキーボードの形をした盤面をクリックしながら配置を組み立て、そのまま `.keymap` として書き出せるようにするものです。

### 日本語環境の「記号がズレる」問題を解決します

ZMKが送るのはキーの**位置**の信号で、そこから文字への変換はOSに委ねられます。そのためUS配列を前提に組んだ配置は、OSがJIS配列と認識した途端に記号が総崩れになります（`@` を押したはずが `"` になる、など）。

このツールの **US⇄JIS変換** は、US側に組んだ配置を「JIS環境でも見た目どおりの記号が入力される」キーコードへ自動変換し、JIS用のレイヤーとして生成します。Shiftの有無で記号が変わるキー（`'` と `"` など）には mod-morph を自動生成して対応します。

## 主な機能

**キー配置の編集**

- 実機と同じ形の盤面をクリックして割り当て
- キーには「実際に入力される文字」を表示（レイヤーの配列規格に応じて変化）
- ドラッグ&ドロップで入れ替え・コピー、Undo/Redo（Ctrl+Z）

**レイヤーグループ**

- レイヤーを US / GENERAL（共有） / JIS などのグループで整理
- グループ単位の並べ替え・色分け。レイヤー番号と参照は自動で追従

**ZMKの機能に対応**

Combo / Mod-Morph / Tap-Dance / Macro / Conditional Layer / カスタムHold-Tap（ホームロウ修飾のキー位置条件つき） / Hold-Tap・Sticky Keyの全体調整 / トラックボール（PMW3610）

**支援機能**

- 書き出し前の整合性チェック（存在しないレイヤーへの参照・未定義ビヘイビアの検出）
- 全設定のJSONバックアップ・復元
- 印刷用チートシートの出力
- キーテスター、ダーク/ライトテーマ
- GitHub連携（リポジトリから直接読み込み・コミット）

**他のキーボードにも対応**

ZMKの物理レイアウト定義（`key_physical_attrs`）を含むファイルを読み込めば、roBa以外のキーボードでも盤面を再現して編集できます。

## 使い方

### 基本の流れ

1. エディタを開く（初期状態は roBa のデフォルト配置です）
2. **☰ メニュー → 読み込み** で、お使いの `.keymap` を読み込む
3. 盤面をクリックして編集
4. **.keymap書き出し** でファイルを保存
5. zmk-configリポジトリの `config/○○.keymap` に上書きしてコミット
6. GitHub Actions のビルド完了後、`.uf2` をキーボードに書き込む

### GitHub連携を使う場合（4〜5の短縮）

**☰ メニュー → GitHub連携** から、リポジトリの読み込みとコミットをブラウザ内で完結できます。

準備として、GitHubで **Fine-grained personal access token** を作成してください。

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**
2. **Repository access** で対象のzmk-configリポジトリを選択
3. **Repository permissions → Contents** を **Read and write** に設定

> **トークンの取り扱いについて**
> 入力したトークンはお使いのブラウザ内にのみ保存され（保存するかは選択できます）、GitHub API以外へ送信されることはありません。共用のPCでは「このブラウザに保存」のチェックを外してご利用ください。

### 困ったときは

画面右上の **? ヘルプ** に、操作方法・キー表示の見かた・ZMKの機能解説をまとめています。各設定項目の **?** マークにも個別の説明があります。

## 動作環境

Chrome / Edge / Firefox / Safari の最新版。編集内容はブラウザに自動保存されます（サーバーへの送信はありません）。

## 開発者向け

単一のHTMLファイルで、外部ライブラリへの依存はありません。

```
index.html   本体（core層 = DOM非依存ロジック / UI層）
tests.js     自動テストスイート
```

テストの実行:

```bash
node tests.js
```

パース・生成の往復一致、US⇄JIS変換の可逆性、各機能の保存・復元など71項目を検証します。変更を加えた際は実行してください。

設計の概要はHTMLファイル冒頭のコメントに記載しています。
